# WhatsApp: El hilo verde

Documental de **15 minutos**, formato YouTube **16:9**, narrado en español por **InodeAi**.

De un rechazo en Facebook y una nota que decía «sin anuncios», a tres mil millones de personas y el juramento que se rompió. Animación 3D original: no usa el logo oficial ni retratos de personas reales.

## Capítulos

1. Dos palomitas
2. Los rechazados (1992–2009)
3. No era un chat (2009–2010)
4. Noventa y nueve centavos (2011–2014)
5. Diecinueve mil millones (19 feb 2014)
6. El candado (2014–2017)
7. La ruptura (2017–2018)
8. Infraestructura (2018–2024)
9. Tres mil millones (2025–2026)
10. Quédate — suscríbete a InodeAi
